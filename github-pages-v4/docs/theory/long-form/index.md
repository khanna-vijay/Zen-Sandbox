# 🎪 Long-Form

> *One document per long-form format — the archived original, five posters, grounded research, and a full mechanics-and-coaching manual.*

Where the five domains above teach the **craft**, this section catalogues the **containers** that craft gets poured into. Each study opens with the source article exactly as archived, then builds outward: five 16:9 posters, two search-grounded research passes on history and comparative anatomy, and a manual covering how the form actually works and how to rehearse an ensemble into it.

!!! abstract "How each study is laid out"
    **Part I — The Original Write-Up** (the source article, verbatim) → **Part II — The Infographics** (five posters) → **Part III — Research Dossier** (history, lineage, literature; then comparative anatomy and pedagogy) → **Part IV — Mechanics, Gameplay and Coaching Manual**.
