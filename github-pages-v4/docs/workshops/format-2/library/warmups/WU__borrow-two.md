# Borrow Two

![Borrow Two — infographic](img/WU__borrow-two.jpg){ .infographic }

> The room builds a silent pool of images from one word, drops them one at a time, and each player leaves holding two that weren't theirs.

`Players 10–20` · `~5 min` · `Complexity 2/5` · `Energy low` · `Contact none` · `Props: none`

## What it warms

Attention and group pulse. Drops the room from physical warm-up into concentration, and trains the specific format habit the session needs: an opening generates material that other players must hold and use, not a set of moments you enjoy and forget. Feeds Format Literacy by making retention the measure of success.

**Role in the cluster:** focus

## Setup

Players stand scattered, arm's length apart, facing into the room. No chairs needed, though sitting on the floor works if the room is small. You need one word ready: an ordinary noun like laundrette, allotment, or ferry.

## How to run it

1. (0:30) Scatter the room. Say the word once. Tell them: eyes closed or soft on the floor, no talking, build three concrete images off that word — things you could see, not opinions.
2. (1:00) Hold the silence for a full minute. Don't fill it. Say the word once more halfway through.
3. (0:30) Eyes open. Explain the drop: no order, one image each, one breath, sit down after you speak. If two people clash, both stay standing and go again later.
4. (2:00) Run the drop until everyone is seated. Keep it slow. Let gaps sit rather than prompting.
5. (1:00) Point at three seated players in turn. Each names two images from the pool that were not their own, out loud, fast. Then say the cue and move on.

## Side-coach

- *"Concrete, not clever — something you could point at."*
- *"One breath, one image."*
- *"Don't plan your turn. Listen to theirs."*
- *"Clash? Both stay standing. Try again later."*
- *"Hold what you hear — you'll be asked for it."*

## Build it up

- Ban any image that repeats an element already dropped — no second laundrette, no second rain.
- After the drop, ask each player to name one image and connect it to another player's image in a single sentence.
- Cut the silent build to fifteen seconds so first thoughts are all they have.

## If it stalls

- If nobody drops for ten seconds, drop one yourself and sit. That usually unblocks it.
- If images come out abstract — 'nostalgia', 'freedom' — stop, name it, and ask for something with a colour or a smell.
- If recall is thin, that's the honest result. Say so, and run the drop again with a new word next week.

## Ask afterwards

1. Which image that wasn't yours are you still carrying, and why that one?
2. What would you do with it if a scene started in ten seconds?

## Scale

| Class size | What changes |
|---|---|
| 10–13 | One group. Run the drop twice — everyone stands again after the first pass and offers a second image. Recall from three players. |
| 14–17 | One group, one image each. Recall from three players, chosen from opposite sides of the room. |
| 18–20 | Split into two groups in opposite corners, same word, running at the same time. Each group recalls from two of its own players. Cut the silent build to 45 seconds. |

## Safety & inclusion

Eyes closed is optional — offer eyes-down on the floor for anyone who prefers it. No contact. Nobody is made to speak: if someone wants out of the drop, they sit at the start and just listen.

## Lineage

In the Long-form opening practice tradition. Long-form groups have always gathered images off a suggestion before a set. Written from scratch here as a focus drill: silence first, then a no-order drop, then a recall test — so the point lands that an opening is only worth anything if someone carries it out of the room.
