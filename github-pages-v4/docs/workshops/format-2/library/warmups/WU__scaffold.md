# Scaffold

![Scaffold — infographic](img/WU__scaffold.jpg){ .infographic }

> One person makes a shape, everyone else sprints in to hold it up, then clears on the call.

`Players 10–20` · `~5 min` · `Complexity 2/5` · `Energy high` · `Contact incidental` · `Props: none`

## What it warms

Pulse, legs and big spatial shapes, plus peripheral vision for what the group is already doing. It feeds Support Work directly: you read an existing shape, add the piece it lacks rather than the piece you fancy, and leave the moment the edit is called.

**Role in the cluster:** activation

## Setup

Standing circle, wide enough for six people to fit in the middle. Push chairs and bags to the walls. No props.

## How to run it

1. (45s) Explain: one person jumps in with a big frozen shape and a sound. Everyone else has three seconds to add a shape that holds theirs up. No touching. Demo once.
2. (60s) Round one. Count the three seconds aloud. When the middle is full, call 'Clear!' — everyone sprints back to the circle edge. Run three rounds.
3. (90s) Drop the count. As soon as a shape lands, bodies go. Run five or six rounds back to back, calling 'Clear!' fast so nobody settles.
4. (75s) Add the rule that nobody may copy the shape already there — you add what is missing. Run four more rounds.
5. (30s) Last round: everyone in, hold it, breathe, then clear and stand still in the circle.

## Side-coach

- *"Go before you know what you are."*
- *"Hold the shape up — don't top it."*
- *"Find the gap. Where is it weak?"*
- *"Clear! Back to the edge, fast."*
- *"Feet in first, decide on the way."*

## Build it up

- Add a single sound to each shape, so the group holds a chord as well as a picture.
- After the shape fills, tap the person who started it out — the rest must adjust so the shape still reads without them.
- Let whoever arrives last call 'Clear!' instead of you. The edit passes to the group.

## If it stalls

- If nobody jumps in, name two people per round as the first responders. Everyone else follows them.
- If the middle stays empty and polite, shrink the circle by two steps so the distance is short.
- If people keep building the same shape, ban standing upright for one round.

## Ask afterwards

1. What told you where to put yourself?
2. Did the shape get better when you added yourself, or just busier?

## Scale

| Class size | What changes |
|---|---|
| 10–13 | One circle. Aim for twelve to fourteen short rounds; everyone should start at least once. |
| 14–17 | One circle, but cap the middle at six bodies — if you arrive seventh, you stop at the edge and watch that round. |
| 18–20 | Split into two circles at opposite ends of the room. Call 'Clear!' for both at once so the rhythm stays shared. |

## Safety & inclusion

No touching: shapes go near each other, never onto each other. Anyone who does not want people close can hold the outer ring of the shape. Low and floor shapes are optional — knees and backs decide. Sprinting is a brisk walk if that suits you.

## Lineage

In the Ensemble group-shape and machine-building exercises from physical theatre training tradition. The familiar version builds a running machine that grows and grows. We froze it, kept the shapes silent and still, and added a hard 'Clear!' call so the group rehearses ending cleanly as often as it rehearses joining — which is the week's actual work.
